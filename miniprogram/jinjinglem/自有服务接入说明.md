# 微信小程序接入自有服务

在微信开发者工具中导入 `miniprogram/source`。这里的 `project.config.json` 使用体验版 `touristappid`；真机预览和发布前，替换成你自己的小程序 AppID，并在微信小程序后台将 `https://jinjinglem.yixiangshe.com` 加入 request 合法域名。域名必须保持 HTTPS。小程序使用的是公开探头接口，不需要后台管理员账号。

当前启用的页面为探头地图、探头详情和路线规划：

| 功能 | 自有接口 |
| --- | --- |
| 探头总数与分页列表 | `GET /api/v1/cameras/count`、`GET /api/v1/cameras?offset=&limit=` |
| 探头详情 | `GET /api/v1/cameras/{id}` |
| 探头评论 | `GET /api/v1/cameras/{id}/comments` |
| 提交评论 | `POST /api/v1/cameras/{id}/comments`，JSON 为 `nickname`、`content` |
| 探头图片 | `GET /api/v1/cameras/{id}/images` |
| 路线规划 | `POST /api/v1/routes/plan` |
| 超时后查询规划结果 | `GET /api/v1/routes/result?openid=` |

接口基地址写在 `miniprogram/source/utils/jinjing-api.js`。地图坐标仅展示后端标记为 `GCJ02` 的记录；列表按 500 条分页获取，搜索在已加载数据中执行。地图点位点击进入详情，评论直接写入统一数据库。

路线规划页用微信地图选起点、终点和最多 5 个途经点；可设置进京证类型和路线偏好。规划由 backend 调用已集成的躲猫猫服务，返回线路后在地图绘制，超时结果按会话 ID 轮询。路线规划依赖后端正确配置躲猫猫采集凭据。实时导航、会员/“我的”和进京证仍保留原始页面文件，但没有接入自有后端；首页入口标记“暂不可用”，点击只提示，不调用原小程序云函数或支付接口。

原始拷贝中的其他页面和配置可能包含第三方服务信息，不应直接作为发布版本提交或上传。建议发布前清理未启用的旧页面、凭据和素材，并用自己的小程序身份完成真机测试。

排查网络问题时，先在开发者工具确认域名白名单和网络请求。线上接口已用微信客户端请求标识验证返回 200；Cloudflare 可能对某些脚本默认请求标识（例如 Python `urllib`）返回 403，这不等同于小程序接口鉴权失败。
