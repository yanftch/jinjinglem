# 微信小程序接入自有服务

在微信开发者工具中导入 `miniprogram/source`。这里的 `project.config.json` 使用体验版 `touristappid`；真机预览和发布前，替换成你自己的小程序 AppID，并在微信小程序后台将 `https://jinjinglem.yixiangshe.com` 加入 request 合法域名。域名必须保持 HTTPS。小程序使用的是公开探头接口，不需要后台管理员账号。

当前启用的页面为探头地图、探头详情、路线规划、“我的”、用户反馈和通用 H5 容器：

| 功能 | 自有接口 |
| --- | --- |
| 探头总数与分页列表 | `GET /api/v1/cameras/count`、`GET /api/v1/cameras?offset=&limit=` |
| 探头详情 | `GET /api/v1/cameras/{id}` |
| 探头评论 | `GET /api/v1/cameras/{id}/comments` |
| 提交评论 | `POST /api/v1/cameras/{id}/comments`，JSON 为 `nickname`、`content` |
| 探头图片 | `GET /api/v1/cameras/{id}/images` |
| 上报新增探头 | `POST /api/v1/camera-reports`，表单上传 `nickname`、`content`、`screenshot` |
| 路线规划 | `POST /api/v1/routes/plan` |
| 超时后查询规划结果 | `GET /api/v1/routes/result?openid=` |

接口基地址写在 `miniprogram/source/utils/jinjing-api.js`。地图坐标仅展示后端标记为 `GCJ02` 的记录；列表按 500 条分页获取，搜索在已加载数据中执行。地图点位点击进入详情，评论直接写入统一数据库。

首页的“最近新增”弹窗复用公开的 `GET /api/v1/cameras?offset=0&limit=20`，取 ID 最大的至多 5 条记录。首次进入展示最新记录；关闭时把最新 ID 保存在小程序本地，之后只有出现更大 ID 才再次展示。用户点选弹窗记录可打开探头详情。现有列表接口不返回创建日期，因此弹窗展示探头编号，不显示未经核实的日期。

## 地图与高德 Key

当前小程序的地图由微信原生 `<map>` 组件渲染，定位使用 `wx.getLocation`，选点使用 `wx.chooseLocation`；这些接口没有高德 Key 配置项。路线规划调用的是本项目 `jinjinglem.yixiangshe.com` 的后端接口，不在小程序中直接调用高德。原始拷贝中的 `utils/amap-wx.js` 与旧配置未纳入当前运行版本，也没有被启用页面引用。

网页端配置的 `AMAP_JS_KEY` 与 `AMAP_SECURITY_JS_CODE` 属于高德 Web 端 JS API，不应直接复制进小程序。将来若要在小程序中使用高德的 POI、地理编码等服务，需要先在高德控制台申请服务平台为「微信小程序」的专用 Key，再按实际功能接入；不要将安全密钥写进小程序包。单纯使用微信原生地图展示现有 GCJ-02 探头点位，无需额外高德 Key。

路线规划页用微信地图选起点、终点和最多 5 个途经点；可设置进京证类型和路线偏好。规划由 backend 调用已集成的躲猫猫服务，返回线路后在地图绘制，超时结果按会话 ID 轮询。路线规划依赖后端正确配置躲猫猫采集凭据。

“我的”页位于 `pages/profile/profile`，参考原页的个人卡片和功能入口布局，使用自有品牌图标。昵称只存于当前设备，不代表后台账号；地图、路线规划、使用说明、限行说明、用户反馈、关于和分享已接入。会员、App 下载尚未接入，均显示“暂不可用”；进京证自动续签入口已隐藏。这些入口不会访问原小程序云函数、支付或公众号。首页“我的”入口已启用；实时导航、会员和进京证首页入口仍标明暂不可用。

用户反馈页位于 `pages/report/report`，需填写昵称、探头线索并上传不超过 5 MB 的截图。提交后只写入 PostgreSQL 的上报待审核表；管理员在 `/reports.html` 核实并填写探头名称、经纬度、原始类型编码，审核通过后才新增统一探头。截图仅用于管理员审核，审核通过后也不会自动公开。小程序后台需将 `https://jinjinglem.yixiangshe.com` 加入 `uploadFile` 合法域名。

通用 H5 容器是 `pages/webview/webview`，其他入口可传入 `url` 和可选的 `title`，例如：

```js
wx.navigateTo({
  url: "/pages/webview/webview?url=" + encodeURIComponent(targetUrl)
    + "&title=" + encodeURIComponent(pageTitle)
});
```

`targetUrl` 只接受 HTTPS 地址。“我的 → 限行说明”已指向 [北京市公安局交通管理局的外埠号牌机动车进京注意事项](https://jtgl.beijing.gov.cn/jgj/lszt/659722/659725/index.html)。真机和发布版本使用 `<web-view>` 前，须在微信公众平台的小程序开发设置中配置 `jtgl.beijing.gov.cn` 为**业务域名**（与 request 合法域名分开）。微信可能要求在目标网站根目录放置校验文件；该政府网站不是本项目控制的域名，若无法完成校验，直接嵌入在正式小程序中可能被微信拦截，需由域名管理方配合或另选可控域名。开发者工具关闭域名校验只能用于本地调试，不能代替正式配置。

原始拷贝中的其他页面和配置可能包含第三方服务信息，不应直接作为发布版本提交或上传。建议发布前清理未启用的旧页面、凭据和素材，并用自己的小程序身份完成真机测试。

排查网络问题时，先在开发者工具确认域名白名单和网络请求。线上接口已用微信客户端请求标识验证返回 200；Cloudflare 可能对某些脚本默认请求标识（例如 Python `urllib`）返回 403，这不等同于小程序接口鉴权失败。
