# Android 版待你确认/补充

代码已按现有服务能力实现；以下事项不会阻止本地编译，但会影响真机使用、发布或支付。

1. **高德 Android 平台 Key**：请在高德开放平台创建 Android Key，绑定包名 `cn.jinjingle.android` 和调试/发布签名 SHA-1，再填入个人 `~/.gradle/gradle.properties` 的 `amapAndroidKey`。网页 JS Key、Web 服务 Key 不能直接用于 Android SDK。若最终包名要改，请先告知，Key 也需重配。
2. **发布包名与签名**：目前暂定 `cn.jinjingle.android`，仅验证 debug 编译。请确认正式包名、签名证书和分发渠道；我再接入 release 签名、版本号和商店发布流程。
3. **设备数据重置后的会员处理**：卸载重装或清除应用数据会得到新的设备标识，原会员不会自动迁移。若需要恢复权益，请提供新的设备标识，由管理员在后台手动处理。是否需要额外的自动迁移机制，可在上线后决定。
4. **Android 会员开通方式**：本版仅支持管理员手动设置 1 个月或 1 年会员，不提供 Android 支付。如将来要在 Android 内购买，再确定支付渠道与资质后单独开发，不能直接复用小程序虚拟支付。
5. **客服微信二维码**：后台已提供上传入口，但仓库内没有你的二维码图片。启动新版后，在 `/manage.html?page=android-users` 底部上传 PNG/JPEG（不超过 2MB）；上传前 App 客服页会提示“尚未配置”。
6. **真机联调**：目前已验证编译及后端自动化测试。Key、签名、安装设备确定后，还需实测地图定位与搜索、截图上传、深色模式、路线接口超时、设备自动登记、客服二维码、会员到期拦截和服务端错误场景。
7. **隐私政策**：Android 首次打开会说明高德地图、定位和设备标识用途，并在同意后初始化 SDK 与登记设备。正式上架前请提供应用隐私政策 URL、运营主体和用户协议，以便补入弹窗及商店资料。

目前 Android 已接入系统文本分享；它没有小程序专用的“分享给微信好友/朋友圈”卡片，也没有探头详情的网页深链。如需同款传播能力，需要你确认 Android 分享落地链接及是否使用微信开放 SDK。
