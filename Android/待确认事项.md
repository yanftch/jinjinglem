# Android 版待你确认/补充

代码已按现有服务能力实现；以下事项不会阻止本地编译，但会影响真机使用、发布或支付。

1. **高德 Android 平台 Key**：请在高德开放平台创建 Android Key，绑定包名 `cn.jinjingle.android` 和调试/发布签名 SHA-1，再填入个人 `~/.gradle/gradle.properties` 的 `amapAndroidKey`。网页 JS Key、Web 服务 Key 不能直接用于 Android SDK。若最终包名要改，请先告知，Key 也需重配。
2. **发布包名与签名**：目前暂定 `cn.jinjingle.android`，仅验证 debug 编译。请确认正式包名、签名证书和分发渠道；我再接入 release 签名、版本号和商店发布流程。
3. **Android 新用户注册/登录**：现有后端只支持微信小程序登录以及小程序生成的 App 一次性动态码。Android 已实现动态码换会话；全新用户必须先在小程序创建账号才能登录 Android。若希望 Android 独立注册，请确定手机号验证码、微信开放平台登录或其他方式，并补相应后端接口。
4. **Android 购买会员**：后端 `/api/v1/members/orders` 必须附带小程序 `wx.login` 临时码，支付由 `wx.requestVirtualPayment` 发起；Android 无法复用这条支付链路。Android 已实现会员权益与订单查看，不伪造支付。请确定 Android 的支付渠道、资质和是否需要应用内购买，确认后再开发独立订单和支付流程。
5. **真机联调**：目前要求只保证编译通过。Key、签名、安装设备确定后，还需实测地图定位与搜索、截图上传、深色模式、路线接口超时、会员登录会话和服务端错误场景。
6. **隐私政策**：Android 首次打开会说明高德地图和定位用途，并在同意后初始化 SDK。正式上架前请提供应用隐私政策 URL、运营主体和用户协议，以便补入弹窗及商店资料。

目前 Android 已接入系统文本分享；它没有小程序专用的“分享给微信好友/朋友圈”卡片，也没有探头详情的网页深链。如需同款传播能力，需要你确认 Android 分享落地链接及是否使用微信开放 SDK。
